# Research

SpecSync does not measure the extensionless dispatcher, so the committed coverage threshold is explicitly advisory at 0 rather than presenting vacuous 100% coverage. A blocking native lane covers ShellCheck, Bash parsing, help, a deterministic decode fixture, malformed-input failure, and manifest wiring.

The plugin decodes but does not verify JWT signatures; the canonical spec makes that security boundary explicit.
